# 证据纪律（分析类任务）

- **孤证不证**：任何结论必须由至少两条**来源独立**的证据支持。同一张表换不同 SQL 查出两次结果，仍然只是**一条**证据。用户明确要求：所有分析类任务遵守此标准。
- **时间吻合 ≠ 因果**：时间线重合只能排除「不可能」，不能确证「就是它」。同期发生的多件事必须逐一尝试排除，不能挑最顺眼的那件当答案。
- **必须主动找反证**：先构造能推翻假设的检验（例：「如果 X 是原因，那么在 X 发生之前该指标应该没有变化」），再去查。只检索支持证据等于自我确认。
- **标注证据等级**：直读数据（事实）> 多来源交叉一致 > 时序/相关性吻合 > 机制推断 > 猜测。结论里必须写明当前落在哪一级，禁止用高等级语气陈述低等级证据。
- **跨源交叉**：尽量用不同系统、不同存储互相验证（数据库表 + 产品分析平台 + 会话录屏 + 发布/变更记录）。单一系统内部的自洽不算交叉验证。
- **区分「结构变化」与「个体行为变化」**：总量变化要分解为 mix（人群结构）与 rate（各群自身行为），否则会把「换了一批人」误判成「这批人变差了」。
- **对自己的分析适用同一标准**：不得用孤证支撑自己的判断；只拿到一条证据时，必须明确说「这是待验证假设」，而不是给出结论。
- **数据不可信就弃用**：同一指标两次查询结果显著不一致时，声明该数据不可靠并停止使用，不要挑一个顺眼的继续算。已发现的关键不确定性必须在结论中披露，不得隐去。
