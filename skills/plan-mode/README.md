# plan-mode

📋 Enter collaborative planning mode for complex multi-step tasks.

## What it does

Helps you break down complex tasks into manageable steps before execution. Perfect for:

- Multi-file refactoring
- Feature implementation
- Bug investigation
- Any task that benefits from thinking first

## Installation

```bash
npx skills add https://github.com/pipi32167/million-skills --skill plan-mode
```

## Usage

Trigger planning mode by saying:

- "plan mode"
- "make a plan"
- "let's plan"
- "think before you code"

The skill will:
1. Understand your goal
2. Break it down into clear steps
3. Present the plan for your review
4. Wait for your approval before executing

## Why use plan mode?

- Reduces errors by thinking through the approach first
- Gives you visibility into what will happen
- Allows course correction before code is written
- Better outcomes for complex tasks
